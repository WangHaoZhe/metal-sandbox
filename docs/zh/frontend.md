# 图形界面

前端是原生 SwiftUI App，不是 Electron/WebView，也不是另一套 sandbox 后端。

## 安装与首次使用

打开安装 DMG，把 `Metal Sandbox.app` 拖入 Applications（也可放在用户的 `~/Applications`），然后双击打开。App 内含全部项目 CLI/runtime，无需克隆源码、安装 Swift 包或手动配置二进制路径。

DMG 同时提供 `README.md`、`docs` 文档和 `examples` 示例题包。可将它们复制到本机后阅读、编辑或导入。

首次点击「启动服务」，阅读可信代码提示后确认。若已运行兼容服务，前端通过 `status` 和 `list` 连接，不会启动第二个管理器。每 UID 仍仅允许一个管理器，换 state-dir 不能绕过此限制。

运行需 Apple Silicon Mac、Apple Command Line Tools。没有工具链时可自行运行 Apple 的 `xcode-select --install`；App 不会下载代码、修改系统工具链或要求 root。声明最低 macOS 13；真正的 Liquid Glass 需要 macOS 26+，旧系统采用标准原生控件。alpha 版尚不保证所有硬件和系统组合兼容。

本地生成的 App 使用 ad-hoc 签名，不是 Developer ID 签名或公证包。跨机器传输后可能触发系统安全检查；不要关闭 Gatekeeper、删除 quarantine 或重新签名系统程序。本版本的本机可用性不等于已通过对外分发认证。

## 页面与命令映射

下表除注明外均调用 `sandboxctl sandbox`，状态目录以全局 `--state-dir` 参数传入 CLI。

| 页面/动作 | 实际命令 |
|---|---|
| 总览、定时刷新 | `status`、`list` |
| 总览 → 添加节点、连接设置 → 添加从节点 | `sandboxctl cluster-ssh scan` / `connect`；向导核对主机指纹，通过标准输入传递密码并安装公钥，检查远端服务后保存配置 |
| 创建 N 个 | `create --count N [--name NAME]` |
| 集群节点与动态调度 | `create --node ID --dynamic-scheduling`；连接设置中选择节点角色、增删从节点、设置共享目录，空闲时保存并应用，有活动实例或任务时显示待应用 |
| 侧栏单选右键重命名 | `rename ID NAME`；空名称恢复 ID 简称 |
| 实例详情 | `inspect ID` |
| 停止、停止全部 | `stop ID`、`stop --all` |
| 永久删除（确认后） | `delete ID --confirm` |
| 删除残留 → 在访达中显示 | `reveal-containers BUNDLE_ID...`，仅使用该次成功删除返回的已确认身份 |
| 侧栏右键批量停止 / 删除 | 对确认列表逐个调用 `stop ID` / `delete ID --confirm` |
| 侧栏单选 / 多选 → 在访达中显示 | 一次调用 `reveal-containers BUNDLE_ID...` 定位所选实例的当前物理容器，不启动实例；尚无物理容器的实例跳过并提示 |
| 启动原实例 | `start ID`，保留 ID、原工作区和私有 HOME |
| 从快照克隆 | `restore ID`，返回新的逻辑 ID，仅复制工作区 |
| 在终端中打开 | 在 macOS 终端运行相同 CLI 与连接设置的 `enter ID` |
| 准备脚本提交 | `exec ID --cwd REL --timeout S --detach -- PROGRAM ARGS...` |
| Claude/Codex 轨迹、会话选择和增量刷新 | `trajectory ID [--session PATH] [--after CURSOR]` |
| 结果、取消 | `wait EXEC_ID`、`cancel EXEC_ID` |
| 终端连接、逐条输入及高级选项 | `enter ID`，通过 `:run` 传入命令、超时和可选目录（不是 PTY） |
| 工作区目录树、展开、分页 | `ls ID REL [--after NAME]` |
| 文件预览、下载 | `read` |
| 准备脚本与 prompt | 两次 `write`，随后 `exec -- /bin/sh ./setup.sh` |
| 快照导入、导出 | `import`、`export` |
| 保存后台快照（不导出文件） | `snapshot ID` |
| 导出限定权限 Handle | `grant` |
| 高级人工恢复 | `recover --confirm-processes-cleaned --note TEXT` |
| 关闭服务 | `shutdown` |
| 启动服务 | `metal-sandboxd --allow-trusted-code` |
| 实例 → 验收 | `verify ID [--from TASK_FOLDER] --timeout S --detach`，通过 `executions` / `execution` 查看历史与结果 |

按钮不会调用私有 RPC、直接打开容器目录、启动候选二进制或操作 GPU。选择本地文件仅用于 CLI 的输入输出。前端创建的临时文件、偏好和公开导出的结果，不是后端内部状态。

总览和侧栏的「待完成命令」包括顶层任务及已接入的 Bash 子任务，串行和并行都统计：一个 Claude 主会话加三条未完成 Bash 会显示 4；结束或取消后扣除。它不是系统进程数，也不是 GPU 活跃数。「串行执行槽」不包含并行任务。可用[双 Sandbox Metal 示例](native_operations.md#体验串行调度)观察非白名单任务的 2 → 1 → 0。

边栏每个 Sandbox 右侧显示该实例的待完成命令数，包含运行中和排队中的串行/并行任务，不是子进程数量；随列表刷新更新。空闲显示 0，计数暂不可用时显示「—」。

拖选、Cmd/Shift 多选及 Cmd+A 仅选择 Sandbox。经过或追加点击“总览”“操作记录”“连接设置”时，已有 Sandbox 选择和页面保持不变；普通单击这些导航项仍可切换页面。

## 常用流程

### 创建、编辑和执行命令

实例页签顺序为「概览 → 准备 → 轨迹 → 验收 → 终端 → 文件 → 配置与快照」。

1. 点击「创建 Sandbox」，选择 1–16；活动实例数量受“连接设置”中的节点最大并发实例数限制，默认每节点 32。展开「高级选项」可选择白名单（命中并行，其余串行）或黑名单（命中串行，其余并行），并编辑 JSON。默认沿用服务配置；首次切换到另一模式时提供空列表，来回切换保留各自草稿。白名单使用 parallel，黑名单使用 serial，两者不能混用；非法 JSON 或与所选模式不一致时不能创建。黑名单为空会允许所有任务跨实例并行。弹窗收起时为小框，展开高级选项后增大，收起后缩回；窗口尺寸与内部布局同步更新，表单可滚动。
2. 创建窗口直接显示「导入题包…」，选择包含 `agent/` 和 `tests/` 的题包文件夹。选取后自动载入 `agent/setup.sh` 并展开准备编辑器，可先填写配置再创建。每个副本只导入 `agent/` 内容，再保存编辑后的脚本并提交执行；清空脚本则只导入、不执行。创建完成前请勿修改源题包目录。
   也可不选题包，仅填写自定义脚本。副本使用相同创建配置，不等待前一个任务完成；一个副本导入失败不会执行它的脚本，也不阻断其余副本。不自动重试或删除实例，不复制其他实例的工作区或 HOME。
3. 选择实例，在「文件」页浏览、预览或下载项目文件。
4. 在「终端」页输入项目需要的命令，按回车执行。
5. 根据输出继续修改文件，或执行下一条命令。

按项目自身的构建说明编译和运行。命令解析由 CLI 完成，shell 和候选程序均在 sandbox 内执行，不在宿主 shell 展开。

实例的启动、停止、从快照克隆和删除位于右上角工具栏左侧，随后依次是刷新、新建、更多，最右侧为搜索框。按钮只显示图标，悬停可查看用途；实例操作针对主页面显示的实例，可用状态由实例状态决定。

搜索框使用系统原生工具栏搜索，宽度随窗口可用空间调整，收起侧栏后仍可搜索。搜索只筛选边栏，不切换当前实例或标签页；清空搜索会恢复当前实例的边栏高亮。点击搜索框外或切换窗口会结束编辑焦点，但保留搜索文字和筛选结果。侧栏开关与实例操作使用圆形玻璃控件；刷新、新建、更多共用一个原生玻璃分组。实例标签栏按等宽铺满内容区。

### 启动与克隆

已停止的实例可点击「启动原实例」：保留 ID、原工作区、私有 HOME 和已安装工具，不重放旧进程。旧 Handle 需重新授权。另保留「从快照克隆」：创建新 ID，仅复制已保存的工作区，不包含 HOME。节点隔离时需先按恢复流程检查处理，启动不能绕过隔离。

### 轨迹

「准备」之后的「轨迹」页以对话卡片显示 Claude/Codex 文本、思考、工具调用、返回结果和错误，不直接展示 JSON。可选择会话；长内容可展开，自动刷新和自动滚动默认开启。读取不占执行队列，可在 Agent 运行时查看。会话结束只表示 harness 退出，不代表题目已通过验证。

支持实例私有 HOME 中的 Claude `~/.claude/rollouts/<session>/events.jsonl` 和官方 `~/.claude/projects/<project>/<session>.jsonl`，同一会话优先显示官方会话文件（包含恢复会话后的记录），没有时才使用 rollout 输出日志；Codex 使用 `~/.codex/sessions/**/*.jsonl`。没有日志时显示空状态；已停止实例也可读取轨迹，无需启动 Agent。工作区快照不包含这些 HOME 日志。mini-swe-agent 的准备脚本将记录保存在工作区 `mini_swe_agent_runs/<session>/`，通过「文件」页查看；Harbor 运行的三种 harness 也可通过 Harbor Viewer 查看。

点击「保存并执行准备」，后台确认接收后弹出「准备任务已提交 / 任务已提交到后台」；这不表示脚本已经完成，保存或提交失败不会显示此成功弹窗。

### 终端

实例页只保留一个「终端」命令入口。自动启动公开 `sandboxctl sandbox enter ID`，输入一行命令后按回车或 ⌘Return。`cd src` 保留该控制台的当前目录，`:help` 查看帮助，`exit` 仅退出控制台。切换页签或实例后，连接、输入草稿、设置和输出保留；可手动断开、重连、清屏。

点击「在终端中打开」，会在 macOS 终端调用相同连接设置的 `sandboxctl sandbox enter ID`。这是独立控制台，不共享内嵌控制台的当前目录、输入或输出记录；`exit` 只退出该控制台，不停止实例。它仍受下面的逐条命令/非 PTY 限制。

「自动滚动」默认开启，新输出只自动滚到底部；横向初始靠左，由用户手动滚动，自动滚动不会改变横向位置。关闭后可停留查看历史输出。

「高级选项」提供工作目录、超时和命令模板。工作目录留空沿用控制台当前目录，`.` 表示 workspace 根目录；填写其他 workspace 相对路径仅覆盖该次命令，不替代 `cd` 保存的目录。超时为正数秒数，默认 30 秒。模板仅有「打印工作目录」「读取题目」，只填入命令，不自动执行或修改超时。展开或收起高级选项不改变执行设置。

输出显示执行 ID、stdout/stderr 和退出码。需要继续等待或取消时，可在「操作记录」输入执行 ID，等待结果或请求取消；断开终端本身不会取消执行。

这是逐条命令控制台，**不是 PTY 终端模拟器**：每条命令默认 30 秒，stdout/stderr 在该命令结束后返回；不支持 vim/top、交互 stdin、作业控制或跨命令 shell 变量。单行最多 8 KiB，不接受多行粘贴；多行任务请保存脚本后运行。显示保留最近 256 KiB 内容。空闲控制台不占槽，候选命令由服务按实例调度规则选择并行或 FIFO 串行。

断开、退出前端、切换连接配置只结束前端自己的 CLI 观察进程，不停止 Sandbox 或取消已提交命令；已提交命令可能继续。停止或删除实例后控制台断开。

### 浏览工作区

进入页面时会重新读取对应数据：实例各页刷新详情，文件页刷新目录和所选文件预览，准备页重新读取入口文件，轨迹及验收页读取最新记录。每次展开环境变量或文件夹也会重新读取；未保存的环境变量、准备脚本和题目草稿不会被自动覆盖。读取失败会明确显示错误，不会把缓存当作读取成功。

「文件」是只读浏览器。左侧为 workspace 目录树，包含隐藏文件、空目录、二进制和大文件；每页 256 项，可点击「加载更多」。右侧显示选中文件的元数据与预览，可刷新预览、下载完整文件，或通过右键菜单在访达中显示。需要修改文件时，使用终端、Agent 或准备脚本。

UTF-8 文本和源码直接显示，只展示开头最多 4 MiB；下载文件没有大小上限。图片、PDF、音视频、RTF 等格式使用 macOS Quick Look（快速查看）；实际支持取决于系统及已安装的预览扩展，不保证所有格式都能显示内容，音视频不会自动播放。

预览通过 CLI 下载到私有临时目录，保留文件扩展名并设为只读；系统预览组件只接收副本，不直接访问容器目录，也不会把修改写回工作区。切换文件或退出前端时释放临时副本。预览不是实时同步，文件变化后可点击「刷新预览」。

目录列表不读取内容，也不跟随符号链接；链接和特殊文件仅列出元数据。目录分页是动态观察，不是快照；并发改名或新增后请刷新。单目录最多扫描 100000 项，路径仍遵循后端限制；超限或无权限会明确报错。停止的实例也可浏览、预览和下载文件，无需启动实例，不占命令调度槽。

### 实例环境变量

创建窗口的「环境变量」可折叠，按键名、键值添加行；同批副本各自保存相同配置。创建后在「配置与快照 → 环境变量」修改，停止的实例也可操作。值按原样传入，不做 `$VAR`、命令替换或 shell 展开；不允许覆盖 `HOME`、`TMPDIR`、`WORKSPACE` 和 `METAL_SANDBOX_*`。

变量在准备脚本、终端命令、exec 及其正常继承环境的子进程中生效。保存影响之后提交的命令，不修改已经运行的进程；更新模型配置后应重新启动 Claude。程序主动覆盖或清除变量仍遵循正常 macOS 行为。

后端按实例 ID 保存在权限为 0600 的私有文件中，不是加密存储；前端不把值写入操作记录，工作区 ZIP 不包含该配置。启动原实例保留配置；同一服务中从快照克隆会复制源实例环境配置。若程序自行打印变量或写入工作区，其输出仍可能进入日志和快照。

题包脚本应读取注入变量，不要用写死的 `export KEY=...` 覆盖它们。随附题包采用此方式。

### 准备环境和题目

打开「准备」页会通过 CLI 读取工作区真实的 `setup.sh` 和 `instruction.md`。缺失时明确显示未记录，不填入示例。草稿按实例保留，切换页面不会串用或丢失；未编辑时再次进入会重新读取，已编辑时不会自动覆盖。可点击「重新读取」放弃草稿并刷新。

「载入脚本…」可手动选择本地脚本，或直接编辑；这些操作只改变草稿。「保存」写入当前内容，「保存并执行准备」依次保存并执行 `/bin/sh ./setup.sh`。任一写入失败就不会继续执行，不回滚已经写入的文件。没有脚本时显示空编辑框，不提供内置 harness 选项。

「导入题包…」只允许选择题包根目录，调用 `sandbox import ID --from DIRECTORY --task`。导入前检查 `agent/instruction.md` 和 `agent/setup.sh` 为非空普通文件，缺少任一文件时不写入工作区。CLI 仅打包 `agent/` 内容（包括隐藏文件），导入 workspace 根目录；`tests/` 留到验收时注入。导入成功后自动重新读取两个入口文件，不自动执行。导入会合并工作区，可能覆盖同名文件和放弃草稿，需确认。格式和完整命令见[题包与 Agent 启动](task_packages.md)。

准备脚本由题包决定，可安装工具、配置环境或启动任意 harness，App 不判断脚本是否使用 Claude、Codex 或其他程序。也可以在脚本中用 `export` 提供模型配置；API key 会明文保存到工作区并随快照导出，分享前必须移除。可按所用工具的支持情况改用私有 HOME 配置。

创建实例时「允许出站联网」默认勾选；取消勾选等价于 CLI `--no_network`，创建后不支持热切换。准备超时支持文本输入和上下箭头，默认 3600 秒、接受任意正数秒数；包含脚本的全部执行时间。运行采用非交互模式，没有 PTY；查看执行结果使用操作记录。脚本退出不关闭 sandbox，对话和产物位置由题包脚本决定。

启动原实例保留私有 HOME；从快照克隆不复制 HOME 中的安装、配置或会话，需重新准备。准备文件的文本编辑预览最多为 4 MiB；超出时明确报错、不截断保存，仍可在终端编辑完整文件。

### 配置与快照

展示本实例创建时保存的白名单/黑名单模式及 JSON，可在固定高度框中滚动、选择复制，只读；停止后仍可查看，启动原实例或从快照克隆时沿用。这里提供快照操作与 Handle 授权。

点击「保存快照」更新后台恢复点，不必选择导出文件。快照保存整个工作区的文件和空目录，不包含命令执行历史、私有 HOME、进程内存或 GPU 状态。实例概览中的「快照内文件数」「快照大小」对应最近一次已保存的快照，不代表工作区当前大小。

文件修改本身直接保存在磁盘。普通命令、文件写入和导入不生成快照；显式保存、完整导出或停止时更新，新建实例保留初始快照。停止后的文件编辑也应在克隆前重新保存。保存快照要求该实例空闲，不会中断正在运行的任务。

快照导出为 标准 ZIP/ZIP64 分块归档，无单文件或快照总字节上限。导入先校验归档，再合并并覆盖同路径文件；写盘失败可能部分成功，不是整份事务。恢复快照创建新 ID，不重放执行。

导出的 Handle 是凭据，前端不读取其内容。只交给可信工具适配器，不上传到候选 sandbox。权限由原后端验证。

## 结果、取消与异常

操作记录会同步后端提交的顶层执行，包括 GUI、CLI 和准备任务，按执行 ID 去重；排队和运行状态随刷新更新。列表先加载最近记录及所有未完成任务，可加载更早的执行；选中记录后读取完整命令与结果。Claude 的 Bash 子任务仍在轨迹中查看。普通前端操作（如刷新目录）只记录在当前前端会话中。

文件树中右键普通文件或文件夹可选择「在访达中显示」，workspace 标题也提供此入口。前端调用 `reveal-file`，由后端验证相对路径；不会启动文件，也不跟随链接或打开特殊文件。

### 永久删除

先停止目标实例、等待该实例的命令结束，再点击右上角红色「删除…」并确认（不可用时显示系统禁用态）。其他实例正在执行或排队的命令不阻止删除，也不会被取消。删除任务文件、快照、已登记物理版本的运行程序和实例列表记录；独立导出的产物、执行日志与恢复审计保留。系统允许时一并删除已清空的容器外壳；权限不足会在结果窗口列出精确残留，不冒充全部清理。不是磁盘安全擦除。

失败显示「删除失败」，保留记录供排查和重试。归属不完整或冲突时拒绝删除；残留清理通过 CLI 提供，前端不直接读取容器。详情见[使用指南](native_operations.md)。


### 执行结果

- 「等待结果」只表示已提交，不能据此判断正在排队还是执行。当前 CLI 在完成后才输出候选日志，前端不伪造实时日志。
- 操作记录可按 Sandbox ID 筛选，默认显示全部；服务操作和无法确定所属实例的记录放在「服务 / 未归属记录」。批量创建的记录可在每个相关实例下查看，克隆记录同时关联源实例和新实例；实例删除后，本次前端会话中已有记录仍可筛选。切换筛选不执行任何后端操作。
- 命令执行记录保存在后端，重开前端可继续查看；文件读取等普通操作只保存在当前前端会话。输出区最多展示前 256 Ki 字符，后端控制实际日志上限。结果文本和规则 JSON 默认从左上角显示，可手动双向滚动。
- 网络/CLI 等待失败可能导致结果未知，不自动重试写操作、重发命令或清空状态。
- 命令运行超时且进程组清理成功，只显示该任务失败；同一实例和其他实例可继续执行，不自动隔离节点。CLI 等待超时与后端命令运行超时是不同情况。
- 取消只调用 `cancel`，不从前端杀候选进程。进程组清理成功后任务记为取消，实例仍可继续执行；清理失败或结果不确定时才保留隔离。
- 恢复需在外部确认进程与 GPU 状态，并停止实例；前端只收集明确勾选和检查说明，不能自动证明 GPU drain。
- 每个实例的「验收」页执行题包 `tests/test.sh`；可只导入题包的 tests/，显示通过/失败、退出码和后台保存的历史日志。停止实例可查看历史，运行验收需要启动实例。它不是独立防作弊裁判；脚本约定和 CLI 用法见[题包验收](task_packages.md#验收答案)。


## 多选与批量操作

在侧栏按住 **⌘** 点选多个 Sandbox，按住 **⇧** 连选。多选时主界面保持上一个页面，不展示选中数量或切换到批量概览。总览与工具页面仍为单页导航。

点击侧栏列表后，按 **⌘A** 全选 Sandbox；有搜索条件时只选当前搜索结果，不选总览或工具行。在搜索框、输入框或编辑器中，**⌘A** 仍然全选文本。

右键选中行可批量停止或永久删除；右键未选中行只针对该行。确认框列出数量及完整 ID，取消不会提交命令。所选项只要有一个状态不符合条件，就禁用整个动作，不静默跳过；删除前需先停止目标实例，后端逐项检查目标是否还有未完成命令，不要求节点队列空闲。

确认后固定目标和连接配置，逐个调用 CLI。单个实例失败、超时或返回无效响应时，记录原因并继续处理其余实例；每项只尝试一次，不会自动重试、回滚或先停止再删除。最终在可滚动、可复制的结果窗口中汇总成功数量，并分别列出失败和结果未知的实例及原因。失败可能已产生部分变更，结果未知不代表未执行，需刷新检查；后端安全限制仍逐项生效。每条命令均记录在「操作记录」。搜索隐藏或刷新移除的行会从选择中清除。

## 外观、生命周期和设置

导航、工具栏、菜单、弹窗及关键按钮采用系统原生外观。右上角按钮使用统一大小的圆形图标样式，macOS 26+ 使用原生 Liquid Glass，删除图标为红色；内容区保留清晰的系统文本/列表背景。材质遵循系统明暗外观及辅助功能设置，不自行绘制玻璃贴图。

工具栏挂在整个导航分栏上，使用系统 API 隐藏独立工具栏背景，让窗口背景连续到顶栏；保留原生侧栏和既有固定视口约束。

全局自动刷新默认每 5 秒执行一次，可在连接设置中调整间隔；窗口可见时，即使 App 不在前台也会刷新，回到 App 时立即刷新。工具栏刷新按钮仍可手动触发。退出前端不停止服务或已提交任务；性能测量时可退出前端以减少自身 GPU 干扰。退出前应记下需要继续等待的执行 ID。

总览的待完成命令卡片中，总数在左、两行明细在右，整体垂直居中并保留边距：“并行任务：x执行中 + x等待中”“串行任务：x执行中 + x等待中”。每个实例的明细位于实例页面标题区右侧，切换标签页时保持显示；侧边栏只显示该实例的待完成总数。数据直接来自后端调度器，四项之和为待完成总数；包含 Agent 主会话及其经适配器提交的 Bash 子任务。

连接设置允许选择其他 CLI 目录、状态目录、刷新间隔。空 CLI 目录表示使用 App 内的 `Contents/Helpers`；CLI 与服务版本/协议不一致时禁用变更操作，且不自动替换服务。

前端偏好由 `UserDefaults` 单独保存；前端启动服务时，日志在 `~/Library/Application Support/MetalSandboxUI/service_logs`。后端状态仍由 CLI 管理，前端不读取 token、内部状态库或系统容器。删除 App 不会删除后端状态与恢复审计。参见[安全边界](security.md)和[停止与清理说明](native_operations.md)。

### 实例名称

创建窗口可填写名称；一次创建多个时依次显示“名称 (1)”“名称 (2)”。留空显示 ID 前 12 个字符。侧栏单选右键 →「重命名」，直接在原名称位置编辑；回车、Tab 或失焦保存，Esc 取消。清空后保存恢复 ID 简称，不弹出对话框。名称支持中文、空格与重复名称；搜索支持名称和 ID。名称在服务重启后保留。主页面始终显示完整 sandbox ID；重命名不会移动目录或中断运行。
